# CODELAB — Alpha 0.1.0

Plataforma educativa web para aprender programación mediante rutas, ejemplos y práctica guiada.

## Tecnologías
- HTML5
- CSS3
- JavaScript (vanilla)

## Catálogo inicial
JavaScript, Python, TypeScript, Java, C#, C++, C, PHP, Go, Rust, Kotlin, Swift, Lua, SQL, HTML y CSS.

## Funciones de esta versión
- Catálogo de 16 tecnologías.
- Búsqueda y filtro por categoría.
- Laboratorio con ejemplos editables de JavaScript, Python, Java y HTML.
- Copiar código al portapapeles.
- Diseño adaptable a móviles.
- Sin dependencias de backend.

## Ejecutar localmente
Abre `index.html` en un navegador o sirve el directorio con cualquier servidor estático.

## Estado
Alpha 0.1.0. El editor permite modificar y copiar ejemplos; no ejecuta código. Cursos, autenticación y seguimiento persistente están previstos para futuras versiones.
